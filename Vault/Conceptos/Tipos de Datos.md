**Definición:** Clasificación de los datos según su formato, estructura y origen, características fundamentales para definir el método de análisis y visualización.
**Resumen Personal:** Es entender si mis datos son números exactos (cuantitativos), textos descriptivos (cualitativos) o ubicaciones geográficas.
**Importancia:** Determina qué tipo de gráfico se puede usar obligatoriamente (ej. no puedes usar un gráfico de líneas continuo para categorías de texto aisladas).
